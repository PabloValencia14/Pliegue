# Pliegue

Nombre: referencia al pliegue del periódico y a la lectura en una superficie de papel.

Símbolo: una p construida con planos de papel y un corte diagonal. El archivo PNG maestro tiene transparencia real. Se usa sin cambios como primer plano del icono adaptable de Android, sobre fondo #F6F5EF; también sirve como máscara del icono de notificación.

Archivos:
- `pliegue-mark.png`: maestro transparente.
- `../../app/src/main/res/drawable-nodpi/pliegue_mark.png`: copia consumida por Android.
- `../../app/src/main/res/mipmap-anydpi-v26/ic_launcher.xml`: icono adaptable.
- `../../app/src/main/res/mipmap-anydpi-v33/ic_launcher.xml`: versión con icono monocromático del sistema.

El nombre se centraliza en `app/src/main/res/values/strings.xml` y se aplica a Android, cabecera y notificaciones. La versión 0.3.0 conserva el identificador y la firma de desarrollo anteriores para poder actualizar sobre la instalación existente.
